# Titanic: Survival Analysis

## Problem
Which passengers were most likely to survive the Titanic?

## Steps
1. Filled missing Age values using the median by class and sex.
2. Created FamilySize from SibSp and Parch.
3. Measured survival rates by sex and class.

## Findings
- Women survived much more often than men in every class.
- Survival fell as class got lower, for both sexes.

## How to run
1. Download train.csv from kaggle.com/competitions/titanic/data
2. Put it in data/raw/
3. Open titanic.ipynb and run all cells.
